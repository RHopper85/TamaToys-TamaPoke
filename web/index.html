NEED A HAND?

A few things to know

Which browser should I use?

Desktop Chrome or Microsoft Edge with Web Serial support. This page can be viewed on a phone, but plugging in and flashing a board requires a compatible desktop browser and a data-capable USB cable.

Will updating erase my Pokémon?

Normal firmware updates use separate flash parts and are designed to preserve the save partition. Back up first, and leave the erase option unchecked unless you're intentionally starting from scratch.

Can I install only Kanto?

Yes. Sprite packs are modular. Install the regions you want now, then add others later using the same board connection.

What if the board won't connect?

Try a different USB data cable or port, close any serial monitor or flashing dialog, and reconnect. For download mode, hold BOOT, tap RESET, then release BOOT.
